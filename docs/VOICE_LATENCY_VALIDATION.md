## 前一轮实施：提交校验与声学对照

本轮增加补丁 `0018-audio-start-timings.patch`、独立网关诊断应用及可复用的
[固定语料测试工具](VOICE_LATENCY_BENCH.md)。`/tts` 请求、音色和原有播放缓冲策略未改；
新增的是首响应体字节、首 PCM、音频驱动首次接受写入的日志。驱动写入不是 DMA
或声学首声。0.1.6 默认产品、按键示例、0.1.8 普通 batch/overlap 和诊断应用构建
通过，主机回归、分析器及不重复试验的续测检查通过，固定上游补丁升级和重复准备通过。

普通候选为 `arcs-mini2-latency-overlap`，ListenAI 0.1.8，CP 1,864,000 B，SHA256
`dfe2534d84443c219975bd39bda77f7ce28dc35a38b9bf12fcd9e705ecdf76c4`。刷写前重新核对唯一
Recovery 身份、原 AP、“小周小周”资源和 PSRAM 声明，独立读取两份完整闪存一致。
写入后独立 CP 读回匹配，所有非 CP 字节在刷写前后相同；后续正常测试音量的配置
写入另计，不把该比对扩大为测试结束后 KV 字节完全不变。普通候选不包含诊断应用。

网关负向检查先做取消三次、不完整 JSON 请求三次，均未取得消息 ACK 或观察到消息
事件；不完整请求返回 400。随后用独立诊断镜像 `a27946b179d66dd4daf3117c76d2bd9ac05fa76c2466132183b5388f074a7cf3`
执行“正向→取消→不完整→正向”：正向均有 200、可解析 ACK 和完整 assistant 事件，
证明观察通道能够接收消息；负向均通过。负向观察窗口为 12 秒，不等同于查询持久化
服务端历史，也不能保证窗口之外不存在迟到事件。

另做一次实际边录边传中的取消：取消前查询已排队 18,432 B，结束时累计排队
36,864 B、采集 PCM 54,400 B；约 107 ms 后在主机收到回合结束摘要。该轮为有意取消，
`valid=87`、云端录音丢样 0，无完整上传、ACK 或 TTS；健康观察通道未见消息事件，
随后正向控制仍通过。107 ms 指采集/上传取消至摘要，不是播放中断的声学延迟。

诊断应用移除前的一次长停顿问答虽收到 ACK，但没有在观察期限内收到完整回复，
作为失败试验保留，没有归因于上传模式，也没有计为性能成功。额外诊断订阅可能影响
原订阅，因此普通固件恢复并重启后再测；重启后的 batch/overlap 预热均完成完整问答。

低音量试跑保留八轮，其中两个模式各一轮因噪声门槛上升而无有效语音，工具自动停止。
随后固定测试条件：MacBook Air 扬声器输出 40%、问题播放倍率 4，设备回答音量 70%，
MacBook Air 麦克风录制 48 kHz PCM；问题为同一“二加三”录音，每轮留 700 ms 安静校准。
测试前设备音量为 20%、Mac 输出为 25%，每次结束均按设置恢复。原音量和临时音量写入
私有清单；固件 VAD 阈值未改变。这些校准试跑与后面的固定条件数据分别保存。

固定条件对照使用同一普通候选镜像、同一设备和同一网络，按轮换正反顺序交错两种
上传模式，端点均为 1200 ms。只用可匹配到固定问题、尾部完整且回答信噪比达标的
录音计算自动声学代理指标；失败和声学拒绝仍保留在总尝试数中。该指标不是人工听测。

在第 19 次试验的 overlap 上传期间观测到 `-0x7780` 对端 TLS 致命告警，Link 断开；
该轮未完成上传或收到 ACK，录音丢样 0，作为失败保留。设备自动重连并恢复订阅后，
显式续测只执行剩余计划位置，不重发已失败的问题。日志不能单独确定对端告警的根因，
不能据此宣称它与上传模式无关。

### 固定短问的 60 次尝试

同一候选镜像内切换运行配置，每种模式各尝试 30 次；这不是原始 `447e107` 与
新镜像的受控前后对比。59 个成功回合均只有一次 `/chat/stream` 和一次回答 `/tts`，
源语音尾部完整、录音丢样 0，首字节/首 PCM/驱动写入的声音代次全部匹配。
唯一失败是上文的 TLS 断线，未重发。所有尝试均保留，分位数仅计算成功且声学有效的样本。

| 指标 | batch / 1200 ms | overlap / 1200 ms |
| --- | ---: | ---: |
| 总尝试 | 30 | 30 |
| 成功且声学有效 | 30 | 29 |
| 回合失败 | 0 | 1（对端 TLS 致命告警） |
| 固定问题尾部→回答能量起点 P50 | 13.878 s | 11.819 s |
| 同一声学代理指标 P95 | 15.296 s | 12.888 s |
| 录音结束→全部进入本地队列 P50 | 2.274 s | 0.094 s |

P50 点估计减少 2.059 s，约 14.8%。29 对完整配对样本的回合差值中位数为
-2.182 s（overlap 减 batch），配对中位数 bootstrap 95% 区间为
[-3.029, -1.570] s。重连前成功样本的两组 P50 为 13.607 / 10.808 s；重连后为
14.178 / 11.990 s，均有同方向改善。这是固定短问的探索证据，不是全部语料或未来
每轮的保证；30 次尝试不足以完成方案要求的 100 轮正式验收或长期稳定性结论。

本次 P50 改善仍未达到方案的 20% 探索门槛，也未达到 6 秒预算。实际收益主要来自
把上传移到收音期间；overlap 的设备时间线中，ACK→完整文字 P50 仍为 5.430 s，
TTS 请求→首 PCM 为 2.737 s，首 PCM→音频驱动首次写入为 0.416 s。没有服务端
追踪，不能进一步把云端等待拆成纯识别、排队或模型推理时间。当前短回答缓冲长度
为 760～1400 ms，不能把这些结果外推为长解释、工具调用或按句播报的收益。

本轮上传任务栈最小空闲观测为 2776 B / 4096 B；仍不是最坏压力工况测量。
配对标识、原始录音、设备日志和完整清单仅保存在私有工作目录；统一用最终分析器
重算各轮录音。两次测试会话保留为独立分段，显式续测不会覆盖旧日志或重复失败轮次。

### 端点完整性

同一合成语料在“一加二”与后续问题之间留约 900 ms 停顿，以批量模式分别测试
1200 / 800 / 1200 / 800 ms。捕获录音结束后立即取消，四轮均未完成上传、无 ACK
或 TTS，录音丢样 0。通过同一录音匹配完整刺激，再比较 VAD 最后有效帧：

| 端点静音 | 次数 | 完整刺激尾部 | 最后有效帧相对刺激尾部 |
| --- | ---: | ---: | --- |
| 1200 ms | 2 | 2/2 | +26 / +72 ms |
| 800 ms | 2 | 0/2 | -4651 / -4688 ms |

800 ms 在句中停顿时结束，后半段未进入录音，因此不启用它作为默认值，也不把
截尾产生的更快结束计入提速。初次端点采样遇到并发控制台长摘要截断，保留为未定
试验；工具改用短行快照读取后完成上述四次检查。此前 60 次对照的摘要均完整，
该工具读取问题没有改写其测量结果。
