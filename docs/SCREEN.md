# 云宝屏幕

本适配使用原机备份中出现的 ST7789P3 单屏驱动，沿用 ARCS Mini 的 SPI0 引脚；不是双 GC9D01N 眼屏板。当前配置为 240 × 240、RGB565、偏移 0、SPI 20 MHz，背光为 70%。不同面板仍须实物确认方向、颜色和可视区域。

| 功能 | 引脚 / 配置 |
| --- | --- |
| 背光 | PA21，PWM0 通道 1，2 kHz，高电平有效 |
| 片选 | PA22，GPIO，软件片选 |
| 数据 / 命令 | PA23，GPIO |
| MOSI / 时钟 | PA24 / PA25，SPI0 |
| 复位 | PB09，GPIO |
| TE 同步 | 禁用 |
| 显示 DMA | 通道 0；音频继续使用原来的 1、2、3 通道 |

板级 `show_status` 只更新请求状态，由优先级 1 的任务绘制，避免在 SDK 输入、链路或音频任务中刷新整屏。115,200 字节的画面缓冲通过 `malloc` 分配到 PSRAM，字形常量保存在 flash，不引入 LVGL。本 UI 使用面板原始方向，不调用 SDK 软件旋转；将其仍会静态分配的旋转缓冲上限设为 16，避免默认的约 15 KiB 内部 SRAM 占用。显示初始化失败会留下诊断信息，语音初始化继续执行。

页面显示云宝名称、眨眼表情和 SDK 状态：启动中、等待配对、连接中、待机、我在听、思考中、正在回答、网络断开、电量低、充电中、更新中。这里只映射 SDK 状态；电池曲线尚未适配，后面三个状态不代表本机已验证相应功能。“待机”跟随客户端在线状态，不能代替服务器注册确认；“正在回答”也可能包含语音下载等待。页面不展示转写或回答原文。

在唯一的 ADB 交互 shell 中执行 `screen` 可读取初始化状态、成功写帧数、SDK 状态编号和最近一次写帧错误。`screen test` 显示红、绿、蓝、白四个色块及边框，15 秒后恢复状态页；官方 `display.show_animation` 也可恢复。`ready=1` 或写帧成功仅代表驱动回执，实物亮屏、字形、方向、颜色还需人工确认。

中文位图来自 [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，字形数据按 SIL OFL 1.1 分发，见 `LICENSE-OFL` 和 `NOTICE`。构建直接使用已生成的字形表，无需 Pillow；重新生成时使用 Pillow 11.3.0、工具中固定 SHA256 的原始字体文件和 `tools/gen_screen_font.py`。
